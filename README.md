# pleb-plant-grower

A realtime houseplant you actually have to look after. Plants grow on the wall
clock rather than a turn counter, so closing the game for a week means coming
back to a week of care — or of neglect. It is rendered as a software RGBA
framebuffer streamed through the Kitty graphics protocol: no SDL, no X11, no
ncurses anywhere in the dependency graph.

![](docs/screenshot.png)

## Features

- **Watering is not a schedule.** Light and temperature drive the drying rate,
  so the interval is derived from conditions and never stored. A dim, cool room
  stretches it — which is why low light causes *overwatering* rather than merely
  slow growth, and why "water every seven days" is the commonest way to kill a
  houseplant.
- **Four plants and four pots**, and the pot is half the watering. Terracotta
  breathes; a cachepot with no hole keeps every drop you give it.
- **Every leaf is a record.** Its size, variegation and damage are fixed when it
  unfurls, so fixing the light only makes the *new* growth correct and a
  well-kept plant is legible as a history rather than as a number.
- **Advice that admits ambiguity.** Brown tips have four causes that look
  identical, so the game names all four and tells you how to tell them apart
  rather than picking one and being confidently wrong.
- **A backdrop you can swap or switch off.** Disabled is a designed look, not a
  degradation.
- **Runs standalone or embedded in kilix-land**, from one archive with no
  conditional compilation. See `docs/EMBEDDING.md`.
- **Headless checks for everything**: `--time-test`, `--calendar-test`,
  `--care-test`, `--rules-test`, `--advice-test`, `--sound-test`, `--selftest`,
  `--save-test`, `--render-test`. Each is deterministic and each is a gate.

## Build

```sh
sudo apt install build-essential python3
make
./pleb-plant-grower
```

`make test` runs every gate. `make release-gate` adds the sanitizers, a clang
build and the release-tree check.

## Controls

| Key | Action |
|---|---|
| `c` | Check the soil — press a finger in. The most useful verb in the game |
| `l` | Lift the pot: what the whole root ball weighs |
| `w` | Water thoroughly, until it runs from the hole |
| `f` | Feed |
| `m` | Mist (it does exactly what misting really does, which is not much) |
| `r` | Rotate a quarter turn |
| `p` | Wipe the leaves — dust genuinely cuts light |
| `t` | Trim damaged tissue; the scar stays |
| `o` | Repot |
| `d` | Empty the saucer |
| `s` | Lift out of the sleeve, or put it back |
| `k` / `j` | Calendar / journal |
| `h` | Help |
| arrows, Enter, Esc | Navigate, confirm, back |

Every other verb — a sip, a bottom-soak, a flush, the water source, feed
strength, moving it, taking a cutting, treating pests — is on the action list.
